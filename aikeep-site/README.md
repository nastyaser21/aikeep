# Aikeep — сайт

Одностраничный сайт-визитка проекта Aikeep (мониторинг стресса, выгорания и вовлечённости сотрудников).

## Структура файлов

```
aikeep-site/
├── index.html          # вся разметка и тексты сайта
├── css/style.css       # стили
├── js/main.js          # автоподстановка года в футере
└── assets/              # логотипы (заглушки — см. ниже)
```

## Логотипы фонда — важно

`assets/fasie-logo.svg` и `assets/putp-logo.svg` — это **свои SVG-реконструкции**
по присланным изображениям (скачать официальные исходные файлы напрямую с
сайтов фонда не удалось — доступ к ним заблокирован для автоматических
запросов). Они похожи по цветам, композиции и смыслу, но не являются
официальными файлами логотипов, поэтому для документов/презентаций, где
требуется точное соответствие бренд-буку, лучше подставить оригиналы.

Чтобы заменить на официальные файлы:
1. Возьмите оригинальные PNG/SVG у кураторов программы или с сайтов fasie.ru
   и univertechpred.ru.
2. Положите их в папку `assets/`, например `fasie-logo.png` и `putp-logo.png`.
3. В `index.html` найдите блок `<div class="support-logos">` и поменяйте
   `src="assets/fasie-logo.svg"` / `src="assets/putp-logo.svg"` на новые имена файлов.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например `aikeep-site`), можно
   пустой, без README.
2. Загрузите в него все файлы из этой папки — либо через веб-интерфейс
   GitHub (кнопка **Add file → Upload files**, перетащите всю папку),
   либо через git:
   ```bash
   cd aikeep-site
   git init
   git add .
   git commit -m "Первая версия сайта Aikeep"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/aikeep-site.git
   git push -u origin main
   ```
3. На GitHub откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
5. Нажмите **Save** и подождите 1–2 минуты — GitHub покажет ссылку вида
   `https://<ваш-логин>.github.io/aikeep-site/`.

Готово — сайт опубликован и бесплатно хостится на GitHub.

## Локальный просмотр перед публикацией

Просто откройте `index.html` в браузере — сайт не требует сборки или сервера.
